# Irfan Hossain Nishat — Portfolio

Premium, responsive Next.js portfolio with a warm ivory default theme and a persistent light/dark toggle. Fragré de Riva is the featured project, followed by WorldHistora, Beat Machine, ScamShield BD, and Discipline Engine.

## Interactive code playground

The Playground section is a real browser-side HTML/CSS/JavaScript editor, not a typing animation. Visitors can:

- Edit separate HTML, CSS, and JavaScript tabs.
- Run the current code in the adjacent preview (`Run preview` or `Ctrl/⌘ + Enter`).
- Reset to the starter example, copy the selected file, or download the complete project as one HTML file.
- Use Tab for two-space indentation.

The preview is sandboxed in an iframe with an opaque origin. A restrictive Content Security Policy blocks network access and external resources. Code runs locally in the visitor's browser; it is not sent to a server or saved. This is intended for small front-end experiments, not a full IDE or a server-side/runtime environment.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. For a production check, run `npm run build` before deploying to Vercel.
